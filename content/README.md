# サイトの中身の直し方

このフォルダの JSON を GitHub の画面で直すと、サイトにすぐ出る(作り直さなくていい)。

- `news.json` お知らせ。`type` は `update`(アップデート)/ `event`(イベント)/ `info`(そのほか)。新しいものを `items` の一番上に足す
- `ranking.json` ランキング。ゲームの OP メニュー「サイト用のランキングを書き出す」でチャットに出た1行を、そのまま全部貼りかえる
- `faq.json` よくある質問 / `rules.json` ルール / `devlog.json` 開発日記

カンマ(,)の付け忘れ・付けすぎがあると読めなくなる(その時はサイトを作った時の中身が出る)。
