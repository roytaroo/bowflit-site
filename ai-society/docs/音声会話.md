# 音声会話 (マイクで住人と話す)

## 流れ

```
 マイク ──▶ voice_input/talk.py ──(文字)──▶ Node.js (npm start)
            ・PTT / 常時会話                   ① 進行役: 名指し判定・誰がどう返事するか
            ・Whisper (faster-whisper)          ② 選ばれた住人が順番に返事 (自分の人格・記憶・それまでの会話)
            ・幻の文章フィルタ                  ③ ゲーム内チャットに表示 + 音声キューへ
                                               ④ VOICEVOX / ゆっくり で合成 → スピーカー
```

- 文字チャットでも、マイクでも、**同じ入口 (進行役)** を通る。人間の発言はすべて「聞こえた住人それぞれの記憶」に残る
- 1つの会話が終わるまで、次の発言は待つ (会話が混ざらない)。プレイヤーと話している間は、住人の独り言や AI 同士の自動返事を止める

## 誰が返事するか (進行役)

| 発言 | 動き |
|---|---|
| `ずんだもん、木を集めてきて` | ずんだもんが返事。社交的な住人が たまに口を挟む (LLM を使わず即決) |
| `みんな、今日はダイヤを探しに行かない?` | 全員が聞く。進行役 LLM が性格・社交性・プレイヤーとの関係を見て 2〜4人を選び、「賛成/反対/面倒/心配/他人に振る」など態度がばらけるように順番を決める |
| `ふぅ、疲れた` (名指しなし) | 近くの住人のうち 0〜2人が反応。誰も返事しないこともある |
| 返事の中で「きりたんはどう思いますの?」 | 返事に `ask` があると、振られた住人が続けて答える (連鎖は最大2回) |

- 進行役には各住人の**公開プロフィールだけ** (性格の一文・社交性・関係の言葉・今していること) を渡す。個人的な記憶は渡さないので混ざらない
- 態度は「目安」として各住人に渡し、性格に合わなければ従わなくてよいことにしている
- 頼みごと (`木を集めて` `ついてきて`) を引き受けると、その行動が予約される。行動は通常どおり安全管理の審査を受ける
- 前に話したことは記憶に残り、次にそのプレイヤーが近くにいるとき、自分から話題にできる

## 使い方

```powershell
# 1) 住人を起動 (マイク入力の受付も起動する)
npm start -- --voice

# 2) 別のターミナルでマイク入力 (初回だけ)
cd voice_input
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt

# プッシュ・トゥ・トーク (F9 を押している間だけ録音)
python talk.py
python talk.py --key ctrl_r          # 右Ctrlで話す
# 常時会話 (ヘッドホン推奨)
python talk.py --mode always
# マイクなしで文字入力 (動作確認)
python talk.py --mode text
```

`config/settings.json` の `player.name` に、**だいきの Minecraft の名前**を入れておく (統合版から Geyser 経由で入る場合は、名前の頭に付く記号も含める)。

### 常時会話の「自分の声を拾う」対策

- 住人の声がスピーカーから出ている間 (と直後0.6秒) に始まった音声は捨てる (`/status` の speaking を見ている)
- それでも拾う場合はヘッドホンを使う

## 音声認識 (Whisper) の選び方

| 方式 | 速さ | 精度 | VRAM | 備考 |
|---|---|---|---|---|
| **faster-whisper small (CPU, int8)** | 3秒の発話を 1〜3秒程度 (推定) | 日常会話なら実用的 | 0 | **6GB GPU の初期設定**。LLM に GPU を譲る |
| faster-whisper medium (CPU) | 遅い (数秒〜) | 高い | 0 | CPU が強ければ |
| faster-whisper large-v3-turbo (GPU) | 速い | 高い | 約1.5〜3GB | 16GB 以上の GPU に買い替えたら `--device cuda --compute-type int8_float16` |
| kotoba-whisper (日本語特化) | — | 日本語で高いとされる | — | 将来の候補。未検証 |
| whisper.cpp | CPU でも速い | 同等 | 0〜 | 別案。今回は未対応 |

住人の名前を Whisper のヒント (initial_prompt) に入れているので、「ずんだもん」「きりたん」などの名前が認識されやすい。

## PC への負荷 (GTX 1660 SUPER 6GB の場合・推定)

| 処理 | どこで | 負荷 |
|---|---|---|
| LLM (qwen2.5:7b) | GPU | VRAM 約5GB。返事1回 6〜12秒 |
| 音声認識 (Whisper small) | CPU | 発話のたびに数秒 CPU を使う |
| 音声合成 (VOICEVOX CPU版) | CPU | 1文 0.3〜1秒程度 |
| Minecraft サーバー + 住人ボット | CPU / RAM | 常時 |

**1回目の返事が聞こえるまで、今のPCでは 10〜20秒程度かかる見込み** (認識 1〜2秒 + 進行役 3〜6秒 + 返事 6〜12秒 + 合成)。
2人目以降は、前の人の声が流れている間に次の返事を作るので、待ち時間は少し短くなる。

速くする方法:
- `floor.director_model` に小さいモデル (例 `qwen2.5:3b`) を指定 → 進行役だけ速くなる (ただし2つのモデルが VRAM に載るので 6GB では厳しい。要実測)
- 名指しで話しかける → 進行役を使わないので速い
- GPU を 16GB 以上にする

## 声の割り当てと規約

| 住人 | 声 | 規約の確認先 |
|---|---|---|
| 四国めたん / ずんだもん / 東北ずん子 / 東北きりたん | VOICEVOX 同名の話者 | 東北ずん子プロジェクトのキャラクター利用規約 + VOICEVOX の各音声ライブラリ規約 |
| 白上虎太郎 / 青山龍星 / ナースロボ_タイプT / 満別花丸 / あんこもん | VOICEVOX 同名の話者 | VOICEVOX の各音声ライブラリの規約 (キャラクターごとに違う) |
| 霊夢 / 魔理沙 | ゆっくり (AquesTalk 系) | AquesTalk のライセンス + 東方Project 二次創作ガイドライン |

- 声は ID ではなく **話者名とスタイル名** で指定している (`voice.speaker_name`)。起動時に VOICEVOX から ID を引くので、`npm run voices` で全員分が見つかるか確認できる
- VOICEVOX はクレジット表記 (例「VOICEVOX:ずんだもん」) が必要。配信・動画にするときは使った全員分を書く
- **ゆっくり音声 (AquesTalk)**: 公式アプリ AquesTalkPlayer は「個人の非営利利用なら無償、商用は使用ライセンスが必要」とされている。AquesTalk1 の使用ライセンスは 6,380円 (OSごと・永続) と報じられている。配信で収益化するならライセンスが必要になる可能性が高いので、公式で確認すること
  - 設定: `voice.aquestalk.command` に、ライセンス条件を満たしたツールの「文章 → WAV ファイル」コマンドを書く。`{text}` `{preset}` `{file}` が置き換わる。コマンドの書き方はツールによって違うので、そのツールの説明書に合わせる (このプロジェクトでは実機未確認)
  - 未設定のあいだは、霊夢・魔理沙は代わりの VOICEVOX の声で話す
- **霊夢・魔理沙** は東方Project (上海アリス幻樂団) のキャラクター。二次創作ガイドラインに従うこと (公式サイトで最新版を確認)
- 白上虎太郎・青山龍星・満別花丸・あんこもん の人格は、公式設定を確認できなかったので**仮設定**。`characters/*.json` の `canon_note` に書いてある。公式設定を確認して書き換えてほしい

## 将来: 自分の声のクローン (まだ実装しない)

用途ごとに必要なものが違う:

| 用途 | 方法 |
|---|---|
| マイクで話した内容を「本人の声」で流す | クローン不要。録音した本人の声をそのまま流せばよい (talk.py で保存・送信を追加するだけ) |
| 文字チャットの発言を本人の声で読む / 本人の声で話す住人を追加 | 本人の声を学習した音声合成モデルが必要 |

候補 (ライセンス・品質は導入時に要確認):
- **AivisSpeech Engine + Style-Bert-VITS2 系の学習モデル**: VOICEVOX 互換の API なので、キャラクターの `voice.url` にそのエンジンの URL を書くだけで、このプロジェクトから使える作りにしてある
- GPT-SoVITS: 少ない録音から声を真似られる。API サーバーあり
- RVC: 声質変換 (話した声を別の声に変える)。リアルタイム向き

注意: 学習に使うのは**本人の声だけ**にする (他人の声を無断で学習しない)。録音データとモデルはネットに上げない。
