# 参考動画メモ: 【検証】11人の話せるAIは本当に協力してハードコアを生き残れるのか？【マイクラ】

だいきが文字起こしした PDF (TurboScribe・30分まで) を、誤変換と話者のずれを直して整理したもの。
文字起こしの直し方の例: ツンダモン/積んだもん/済んだもん → ずんだもん、赤根/アカネ → 琴葉茜、アオイ → 琴葉葵、
レイム → 霊夢、マリサ → 魔理沙、ズンコ → 東北ずん子、イフ → 虚音イフ、ツムギ → 春日部つむぎ、メタン → 四国めたん、
高感度 → 好感度、マインフライヤー → Mineflayer、クロード → Claude、ジェミニ → Gemini、グリーパー → クリーパー。
話者ラベル ([話者1〜5]) は当てにならない (ほぼ全部が [話者1])。内容から誰の発言かを判断した。

## 出演と使っているAI
- 11人: 琴葉茜・琴葉葵・ずんだもん・東北きりたん・東北ずん子・東北イタコ・四国めたん・春日部つむぎ・虚音イフ・ゆっくり霊夢・ゆっくり魔理沙
- 上の3人は各社の中堅モデル: 茜 = Claude Sonnet 5.5 / 葵 = GPT-6.1 Sol / ずんだもん = Gemini 3.8 Flash
- 下の8人は全員 GPT-6 Luna (思考 high・Fast モード)
- 「頭は Claude、体は Mineflayer という普通のプログラム」。体の動きは既にある仕組みをベースに作った
- テスト1セットで API 代が1万円弱

## ルール・設定
- 人間が渡した台本は無し。渡したのは「5日間生き延びること」だけ
- ハードコア: 死んだら即退場 (復活しない)。期間は5日間
- 全員が寝ないと夜は飛ばせない
- 毎晩モンスターが来る (強制的に毎晩7体湧かせる)。昼になってもモンスターは燃えない
- ゾンビは必ずドアを壊すように設定
- 家・ベッドは最初から用意。ベッドを持ち歩いて寝る動きは作っていないので、寝るには家に帰る必要がある
- 共同チェストにはパンが6個だけ (11人に足りないのはわざと)
- 畑の育つ速さは20倍 (5日しかないので)

## 自作システムの中身
- 周りの状況を読み取り → 自分の意思で考え → 他のAIとコミュニケーションする
- 声はゲーム内から直接聞こえる (編集で入れていない)
- 声は16ブロック、叫ぶと36ブロックまで届く。距離が遠いと聞こえないので、話すには近づく必要がある
- AIが知っているのは自分で見たこと・聞いたことだけ
- 誰かが死んでも、見た人と悲鳴を聞いた人しか気づかない
- 死体はそのままゲームに残り続ける。死ぬ間際に言葉を残す (近くのAIには聞こえる)
- 各キャラには性格を渡している。あとはAIが元々知っているキャラのイメージでやりくりする
- 好感度: 初期値3・最高5。画面右下に表示。好感度は上がるだけのことが多いが、殴られると下がる (きりたんが魔理沙を剣で殴ってしまい下がった)
- 「誰が何をしたか」が記憶に残る (葵が、ずんだもんがドアを直したのを見ていて、最終日にそれを話題にする)
- 約束: 約束を結ぶと一緒に行動できる。ただし内部の判断で約束を破ることもある (茜は葵を待たずに鉄を焼くのを優先した)
- 位置は「家から東へ約38ブロック」「家から南東約102ブロック」のように家を基準に伝え合う。目撃情報がリレーされる (イフ → ずん子 → 葵)
- 戦うか逃げるかはLLMが判断し、その判断に沿って体が動く。クリーパーには爆発を誘う動きもできる
- ゲームを映像で見ているわけではないので、見た目や足場の良さは分からない (家の裏の不格好な場所に畑を作る)
- 体と頭が完全には対応していない (木を切っているのに「木が見つからない」と言う、など)

## 1日の流れ
- 毎朝「作戦会議」: 1人ずつランダムな順番で発言する。会議で決めたことが必ず守られるわけではない
- 昼: 会議を元に動く。すぐ木を切りに行く組、まずチェストを確認する組、畑組、洞窟・鉄探し組などに分かれた
- 夕方: 家に帰る。帰ってこない仲間を探しに行く・心配する
- 夜: 家で食べて回復・鉄を焼く・寝る (全員そろわないと朝にならない)
- 毎日の終わりに「死亡者」と振り返り

## 印象的だった場面 (性格が出ているところ)
- 茜: 危ない洞窟に行きたがる。関西弁。葵との約束より自分の作業を優先することがある
- 葵: 茜のママ役。茜を心配して探し回る。最後まで起きている
- ずんだもん: ソロプレイヤー。誰彼かまわず勝負を吹っかける。「僕の手柄なのだ」。盾と鉄の剣で無双 → 洞窟の奥へ1人で行って死亡
- 東北姉妹 (ずん子・イタコ): 畑組。めっちゃ穏やかに協力。種を集め、水辺を探す
- つむぎ: 会議では茜・葵と行動すると言ったのに、いつの間にか畑組に。4日目の朝、ドアを開けて外の敵を倒そうとしてゾンビにやられ、最初の犠牲者に
- イフ: 古風な敬語 (「〜でございます」)。仮面の妖怪でおじさんボイス。かまどの使い方を勘違い。正体を魔理沙に探られる。つむぎの墓と看板 (弔いの言葉) を作った
- 霊夢・魔理沙: 魔理沙は洞窟の戦闘担当 (「後ろは任せたぜ」)。霊夢が魔理沙をからかう。霊夢は帰ってこないきりたんを迎えに行き、ジャンプ斬りでクリティカル
- めたんとずんだもんは裏で張り合っている (ダイヤ・ドアの修理)
- つむぎの死後、残った子たちが自分たちで墓を建て始めた (イフ・ずん子・イタコがそれぞれ墓を作り、墓が3つに)
- 4日目: 2人死亡 (つむぎ・ずんだもん)。文字起こしは30分で切れている

## 30分以降 (4日目の続き〜5日目・まとめ)
だいきが別に送ってくれた30分以降の文字起こしから。誤変換の直し: あね/赤根 → 茜、蒼い/青い → 葵、ズンダもん → ずんだもん、
キリたん → きりたん、つ麦/つぎ → つむぎ、ずこ/ズネ様 → ずん子 (きりたんの「ずん姉さま」)、いこ/イコ → イタコ、
フさん/い → イフ、記念日/記念費 → 記念碑、GPTアストラ・バルスAI → (別の有名な実験の話)。

- 4日目: 葵は茜を探して聞き込みを続ける。「最近見かけた？いつどこで見た？」→ 魔理沙「3分前に家から東へ約56ブロックのところで見たぜ」
  → 「イフから、茜は戸口から南へ向かったのが最後だと聞いた」と、見た時刻・場所の情報が人づてに伝わる
- 魔理沙「夜まであと1分だ。今から探すのは無茶だぜ」→ 葵も帰宅。AIは夜までの残り時間を知っている
- 茜は1人で洞窟探検中、水中のマグマブロック (下向きの水流) に引き込まれて溺死。誰も気づかない
- **死に気づく方法は3つだけ**: 死に際の声を聞く / 死体を見つける / 寝たときに「夜を飛ばすのに人数が足りない」。ゲームのログ (死亡メッセージ) は出さない
- ずんだもんの最期の声「こんなの認めない」は、きりたんにだけ聞こえていた。ただし、きりたん視点では死んだと確定していないので、みんなに伝えたりはしない
- 4日目の終わり: 生存8人。好感度は全部上がった
- 5日目の朝の会議: 全員が茜・ずんだもん・つむぎの死に触れる。葵「お姉ちゃんにまだ作ってあげたい料理があったのに。今日は外で木を集めてみんなの食事を整えるね」
  → お姉ちゃんがいないと、葵は洞窟に行かなくなった (悲しみで行動が変わる)
- 魔理沙が、家の前に建てられた墓をツルハシで壊す (邪魔だから)。家の中・すぐ前には墓を建てられない仕様
- 伝言ゲーム: 霊夢が「ゾンビ！」と言ったのをきりたんが聞いて援護に行こうとし、それを聞いた保護者組 (葵・ずん子・イタコ) が「無茶しないで家に戻って」と口々に言う。
  実際にゾンビを見た人はいないのに、聞きかじった話にみんなが反応し続ける (声の届く範囲を絞ったからこそ起きる)
- 葵は誰とも話さず、1人で茜とずんだもんの墓を建てた (2人の墓を建てたのは葵だけ)。墓碑の言葉:
  茜「大好きなお姉ちゃん、一緒に帰った日々をずっと忘れない」(2日目に2人で帰った日のこと)、
  ずんだもん「家を守ってくれた仲間。扉を直してくれてありがとう」(2日目の朝にゾンビに壊されたドアを直したこと)
  → 細かい出来事を覚えていて、感謝として書く
- つむぎの最期の言葉は「あーしの分まで生きて」。きりたんが「私の分まで生きて」と一人称を間違えたのを、葵が「そのまま刻んで」と直した
- 墓のことを「記念碑」と呼んでいた。看板に言葉を刻む
- 5日目の夜: 生存8人で終了。自分のベッドの近くに敵がいて寝られない魔理沙が、茜のベッドで寝た
- 日記: 記憶の整理と一緒に日記を書かせていた。最終日の葵の日記「お姉ちゃん、いつか会いに行くよ。寂しいよ。これからもずっと大好きだよ」
- 好感度: 裏切りがあると思って用意したが、AIが賢いと変なことをしないので、ほとんど上がるだけだった。
  例外: ずんだもん → めたんだけ2 (作戦会議の最初に煽られて下がり、その後も煽り合いを繰り返した)
- 作者の反省: 「夜は寝る」ようにしたら、寝れば敵が来ないので、家に引きこもって夜は秒で寝るのが最適になりすぎた。
  見せ場を作るために「洞窟を探す」をしっかり入れた。デスゲームとしては甘かった
- 作者もマイクラに詳しくない (「水中のマグマブロックは下向きの水流を作るらしい。今調べた」)
